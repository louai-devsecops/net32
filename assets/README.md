# مجلد الصور

## الموجود الآن

| الملف | الوصف |
|---|---|
| `logo.jpg` | شعار المعهد (وزارة التكوين والتعليم المهنيين) — 256×256، مُستخرج من الشعار الرسمي عندك ويظهر **دائريًا** في التذييل وبطاقة «عن التطبيق». |

## إضافة توقيع شخصي (اختياري)

ضع `signature.png` هنا (صورة توقيعك أو شعارك الشخصي)، ثم في `branding.js`:

```js
signature: "assets/signature.png"
```

## استبدال الشعار

ضع ملفك (PNG بخلفية شفافة أو JPG) هنا ثم عدّل `logo` في `branding.js`:

```js
logo: "assets/logo.png"
```

نصائح:
- صورة **مربّعة** أفضل (تُقصّ دائريًا بـ `border-radius: 50%`).
- لا تتجاوز ~200KB لتبقى الصفحة سريعة.
- إن فشل تحميل الصورة يُخفيها التطبيق تلقائيًا بدل إظهار أيقونة مكسورة.
